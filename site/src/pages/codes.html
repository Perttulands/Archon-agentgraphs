Run statuses

running, waiting_human, blocked, and the final succeeded, picked, failed and canceled. Always check final and resumeAllowed as well. Explained in Run and drive.

run wait and run follow exit codes

CodeMeaning
0Final: succeeded, failed or canceled.
7Final as picked.
3The run needs you (needs-you, or an ask during any-change).
4Changed, with no new ask (any-change).
5--timeout passed first.
6The daemon stayed unreachable for --reconnect.
1Error, such as an unknown run or a --since past the last event.
2Usage, or no --server.

Validation findings

mission validate and run admission report the same findings. All are errors unless marked as a warning.

Graph and routes

route_leads_nowhereA step output or gate route is not wired to a step, gate or End.
unreachable_nodeWarning: no path from the Input card reaches this node.
dangling_connectionA wire's end names no existing port.
duplicate_input_producerA second wire into an input port that takes one feed.
duplicate_node_idTwo nodes share an ID.
mission_countThe mission has no Input card.
several_input_cardsThe file holds more than one Input card; split it.
mission_not_runnableThe Input card's out is wired to nothing.
invalid_endAn End's outcome is not done or rejected.

Steps and staffing

invalid_formation_typeA type other than solo, peer or orchestrated.
invalid_formation_shapeThe slots do not fit the type (one solo slot; two or more peers; one controller and a worker).
unstaffed_slotA slot has no harness and effort.
invalid_slot_settingsThe harness, model or effort cannot start a seat.
unavailable_persona, retired_personaThe slot's role cannot be read, or is retired.
duplicate_slot_id, invalid_slot_idSlot IDs must be unique across the mission and well formed.
invalid_port_kindA kind on an input port, or a kind other than file or folder.

Inputs, outputs and files

invalid_mission_inputA hand-written input with a bad name or kind.
unknown_input_referenceA brief names {x} but no input x is declared.
invalid_mission_outputA hand-written output with a bad name, kind or from.
unbound_mission_outputAn output has no from, or names no step output port.
mission_output_kind_mismatchAn output's kind is not its port's kind.
missing_file, relative_fileWarnings: a referenced file does not exist, or is not absolute.
invalid_human_channelA channel other than notify or session.

Gates, limits and Tools

gate_not_routableA gate lacks what its kinds need, such as a judge chain or a code check.
invalid_judge_relationshipJudge wiring that does not form a chain back to its gate.
invalid_code_gate_profileAn unknown code check or version.
invalid_limitA Limit card unwired, doubled, with a bad value, or a best card without a selecting gate.
empty_limitWarning: a Limit card sets no knob.
invalid_tool, incompatible_media, incompatible_payload_kindA Tool node, or a wire into one, that its profile does not accept.

Run inputs (admission only)

missing_inputA required input is missing or blank.
unknown_inputA value for an input the mission does not declare.
invalid_inputA file or folder value that is not the absolute path of one that exists.

Block and failure codes

Blocks are explained, with their next moves, in Recovery and evidence. Codes that end runs:

path_rejectedA path reached a rejected End.
missing_outputA required mission output was never delivered, or a file output vanished.
limit_reachedWith whenSpent = "fail", the run fails; otherwise it blocks.

API error codes

RUN_ADMISSION_FAILED (422)The start was refused; error.findings lists why.
CONFLICT (409)A stale mission revision or ETag.
BROKEN_LINK (422)A mission symlink whose target is gone.
INVALID_SLOT_SETTINGS (422)Staffing without a harness and effort, or one the harness refuses.
INVALID_AGENT_CARD (422)A role card with a harness, model, effort or unknown field.
ROLE_IN_USE, ROLE_USAGE_INCOMPLETE (409)A role a slot names, or whose use cannot be established, cannot be deleted.
INPUT_OCCUPIED, SELF_WIRE, DUPLICATE_CONNECTIONWiring refused; join with --join.
UNSUPPORTED_FORMATION_TYPENot solo, peer or orchestrated.
INVALID_LIMIT (400)A Limit card write with a bad target, value or whenSpent.
RELATIVE_FILE_REFERENCE (400)A reference file named by a relative path.
INVALID_MISSION_INPUT, INVALID_MISSION_OUTPUT, INVALID_PORTAuthoring refused a bad input, output or port.

The CLI reports the same codes in lower case, such as invalid_slot_settings.

Ledger events

A typical run records run_started, node_started, slot_dispatch, seat_created, seat_prompt_consumed, slot_result, seat_cleanup, node_output, gate_evaluating, gate_kind_result, gate_verdict and an outcome: run_succeeded, run_picked, run_failed or run_canceled. Others include run_blocked, run_resumed, human_input_requested, human_verdict_recorded, pick_started, judge_attempt_failed, limit_warning, token_usage, seat_state, human_ask_delivered and human_ask_fallback. Each event has a sequence number, a timestamp, a type, an actor and the run's ID.

Seat cleanup outcomes and seat states are in Recovery and evidence.
