Conventions

  • JSON responses use one envelope, {"success":true,"data":…,"timestamp":"…"}; errors carry an error object with a code and message. The raw theme document is the one exception.
  • There is no authentication. See Trust and network.
  • Mission edits carry the revision or ETag they read. A stale one answers 409 CONFLICT: The mission changed since it was read; reload it and retry. An edit that changes nothing saves nothing and answers 200.
  • A mission patch carries exactly one operation; a patch naming two is refused whole with 400.
  • A rejected run start answers 422 RUN_ADMISSION_FAILED with error.findings as {code,nodeId,message}.

Evidence and files

Every evidence route reads one run; served text is {text,bytes,truncated} with secret patterns redacted.

RouteDoes
/api/runs/{runId}/evidence/nodes/{nodeId}A node's frozen definition, attempts, dispatches, outputs, gate evaluations, picks and problems.
/api/runs/{runId}/evidence/problemsEvery block and error, and the event that ended the run.
/api/runs/{runId}/evidence/attemptsEvery step's attempts with outputs, verdicts and files; ?node= for one step.
/api/runs/{runId}/evidence/briefs/{dispatchSeq}The brief that dispatch sent.
/api/runs/{runId}/evidence/artifacts, /evidence/artifacts/{name…}The artifact list; one artifact's preview.
/api/runs/{runId}/artifacts/{name…}An artifact's bytes, sandboxed (Content-Security-Policy: sandbox), with ranges.
/api/files/preview?path=, /api/files/raw?path=Any file a mission references by absolute path: preview, or bytes.
/api/files/directory?path=An absolute directory's subdirectories and regular files, directories first; used by the start dialog's path picker.

All evidence and file routes are GET.
