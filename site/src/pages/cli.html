The text is generated with an empty home directory so it is the same on every machine. Your binary's help adds the Codex models listed in your $CODEX_HOME/models_cache.json.

Global flags

FlagUse
--server <url>Send the command to a daemon. Required for every runtime command; authoring through it shows edits live in an open cockpit. A failure is final: nothing falls back to local files.
--workspace <state-dir>Work on a state directory's files offline. For a directory no daemon serves.
--versionPrint the CLI's version and source commit. archon --server <url> version adds the daemon's.

There is no default: a command given neither --server nor --workspace says so and stops. With --server, authoring commands print the same output as offline; runtime commands print the daemon's {success,timestamp,data} envelope, except run status, run gates, run seats, run attempts and gate request, which print text unless you pass --json. run ask, agent spawn and agent attach work offline only.

Nouns and commands explain themselves: archon <noun>, archon <noun> -h and archon <noun> help list a noun's commands; an unknown command is named and the noun's commands listed.
