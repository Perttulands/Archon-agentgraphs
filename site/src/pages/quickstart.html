You need archon and archond on your PATH, from an archive or a source build (Install). Lab needs no tmux and no model CLIs.

Run the delivery mission in lab

  1. Choose a state directory and the examples

    The state directory is where the daemon keeps missions and run history. The examples ship in the archive's share/archon/examples, or in examples/ of a checkout.

    export ARCHON_STATE="${XDG_DATA_HOME:-$HOME/.local/share}/archon/state" export EXAMPLES="$HOME/.local/lib/archon/current/share/archon/examples" # or: "$PWD/examples" in a checkout umask 077 mkdir -p "$ARCHON_STATE/.archon/missions" "$ARCHON_STATE/.archon/notes"

  2. Import the delivery mission

    There is no import command: a mission is imported by copying (or symlinking) its TOML into the state directory. Then validate it and lay out its cards.

    cp "$EXAMPLES/delivery.mission.toml" "$ARCHON_STATE/.archon/missions/" cp "$EXAMPLES/delivery.notes.toml" "$ARCHON_STATE/.archon/notes/" archon --workspace "$ARCHON_STATE" mission validate delivery archon --workspace "$ARCHON_STATE" mission arrange delivery --json > /dev/null

    mission validate prints delivery 0 errors 0 warnings. --workspace works on the files directly; it is for a state directory no daemon is serving.

  3. Start a lab daemon

    Leave it running in this terminal; Ctrl+C stops it.

    archond --executor lab --state-dir "$ARCHON_STATE" --listen 127.0.0.1:8091

    From a source build, add --ui-dir /absolute/path/to/archon/dashboard/dist (after npm ci && npm run build in dashboard/); an installed daemon finds its bundled cockpit by itself. The daemon prints Archon coordinator http://127.0.0.1:8091 when it is listening.

  4. Open the cockpit

    Open http://127.0.0.1:8091. On Missions, choose Delivery. Things to try:

    • Click a card to open its window beside it. Every field reads in full and edits in place, with Undo and Redo in the toolbar (Ctrl+Z, Ctrl+Shift+Z).
    • Click a slot to open its staffing sentence: Plan is planner on Claude Code · opus · xhigh. Each word opens its own list.
    • Read the note stickies: the operator's intent, kept on the canvas.
    • Switch between Canvas and Flow, which shows sequence, feeds and gating as a line.
    • Open Agents to see the seven built-in roles and which slots use each.

  5. Run it in lab

    Delivery takes one input, change. Its Beads review gate is a judge gate, and in lab a judge passes only if it finds exactly one archon-verdict block in what it reads, so put a synthetic one in the input. In a second terminal:

    export ARCHON_SERVER=http://127.0.0.1:8091 archon --server "$ARCHON_SERVER" mission input delivery cat > /tmp/lab-change.md <<'EOF' Add a CSV export to the report page. ```archon-verdict {"verdict":"pass","reason":"Lab fixture","evidence":["Simulated input"]} ``` EOF RUN=$(archon --server "$ARCHON_SERVER" mission run delivery \ --input-file change=/tmp/lab-change.md --bead demo-1 --json | jq -r .data.runId) archon --server "$ARCHON_SERVER" run wait "$RUN" --until final

    run wait prints Run … (mission "Delivery") succeeded at #33. and exits 0. Without the fixture the run would block at the judge, which is what lab is for: proving routing, not judging work.

  6. Inspect what happened

    archon --server "$ARCHON_SERVER" run list archon --server "$ARCHON_SERVER" run status "$RUN" archon --server "$ARCHON_SERVER" run attempts "$RUN" ls "$ARCHON_STATE/briefs" # lab-*.md: each brief as a seat would have received it

    In the cockpit the run appears under Delivery as Run 1. Choosing it shows each step's output chips; N attempts on a card opens the attempts window. Lab outputs read lab-fake output from planner using claude-code for Plan: honest about being simulated.

Where to go next

  • First real run: the same loop with a real agent.
  • Build missions: write your own, starting from a one-step mission that validates.
  • Limit cards: lab can also rehearse a best-of-N pick with an archon-pick fixture.

No authentication

The daemon serves its API and cockpit to anyone who can reach the listener. Keep --listen on loopback or another interface you trust.
