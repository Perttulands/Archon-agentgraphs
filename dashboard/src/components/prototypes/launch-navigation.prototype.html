What this prototype can do

It changes an in-memory example only. The folder paths are illustrative. Reloading clears everything. There are no APIs, created directories, saved browser data or real agents.

1 · New workspace · form-ls8

Recommended for a new mission. No path entry is needed. Optional location details remain inspectable and editable. Tradeoff: more folders to manage; existing repositories need an explicit choice.

2 · Recover drafts · form-7mk

Keep a separate draft per board in this tab. Tradeoff: old text can linger. Show the draft and provide Discard; reloading clears it.

3 · Persistent footer · form-5bc

Start and Close remain visible while the form scrolls. Tradeoff: less room for inputs. Review step gives a compact checkpoint but adds a click.

4 · Keep board · form-16s

Agents can be a short detour. Tradeoff: the board remains selected while the view changes; make that context explicit.

5 · Search and focus · form-7ce

Read a selected step at useful size and use Fit to return. Tradeoff: focused reading hides the full graph until you return.
