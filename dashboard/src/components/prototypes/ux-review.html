Start with an idea, keep your place.

Thirteen small usability improvements are implemented. Eight workflow choices are ready to try before we adopt them. Start with the missing workspace step.

Workspace creation is a proposal. The live launch still requires an existing server folder. In the proposed default, Archon creates the workspace and keeps its location available to inspect.
Try starting a mission →Create a workspace, recover a brief, keep launch actions in reach, and move between the board and its agents without losing your place. Try runs and decisions →Find a previous run, see where your decision leads, and choose which peer to talk with.

Both demos run entirely in this page's memory. Their controls use example data and simulate actions. Reloading resets them. Each has free play and guided walkthroughs.

Thirteen small improvements

  • Keyboard focus stays inside Start mission and returns to its opener.
  • Dispatch and attempt limits explain what they count.
  • The time limit also reads in hours and minutes.
  • Numeric limits can be cleared and replaced naturally.
  • Copy path reports success or refusal, with a selectable fallback path.
  • Files have an explicit Download action.
  • The board's agent roster can be searched and cleared.
  • Editors show their existing save and cancel shortcuts.
  • Notes explain how they differ from executable briefs.
  • A successful field save gets a local confirmation.
  • Truncated gate inputs link to their run evidence.
  • Run statuses use readable words.
  • Answer drafts say when they are saved, restored or unavailable.
